Quick start

三步完成接入

可以直接把安装 Prompt 粘给 Codex，也可以使用下面的命令行步骤手动安装。

01
推荐方式

把这个 Prompt 粘贴给 Codex

Codex 会读取仓库说明，安装项目，配置 API Key，并验证 Hook 是否可用。

Codex Prompt 
请安装并配置 Codex Jev Preflight。

要求：
1. 阅读 https://github.com/wellkilo/codex-jev-preflight 的 README。
2. 从源码安装项目，并运行 codex-jev-configure 配置 TypeSafe Jev API Key。
3. API Key 必须隐藏输入，不要要求我在聊天中粘贴。
4. 运行 codex-jev-install 安装全局 UserPromptSubmit Hook。
5. 验证 Hook 输出，并告诉我需要重启 Codex 还是新建任务。
6. 不要覆盖 ~/.codex/hooks.json 或 ~/.codex/AGENTS.md 中的其他配置。
02

安装命令行工具

Shell 
git clone https://github.com/wellkilo/codex-jev-preflight.git
cd codex-jev-preflight
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
03

配置并安装 Hook

Shell 
codex-jev-configure
codex-jev-install
# 重启 Codex 或新建任务
# 如需自动信任 Hook：codex-jev-install --trust

How it works

一次调用，四维判断

Hook 在 Codex 开始工作前运行，并把结果作为附加上下文注入当前任务。

01

UserPromptSubmit

Codex 将当前用户提示传给 Hook。

02

Jev asks

→
03

Context injected

→
04
